Bonjour, je suis Le Blanc

Programadora full-stack freelance y desarrolladora de videojuegos indie bajo mi propio sello Code Violette. Francesa de nacimiento, actualmente residiendo en Barcelona.

Con una mente analítica y un ojo para el diseño minimalista, me especializo en crear soluciones de software elegantes y eficientes. Cuando no estoy programando aplicaciones web complejas, desarrollo juegos indie con mecánicas innovadoras y estética cuidada.

Mi actual proyecto es "Neon Cipher", un juego de puzzles narrativo ambientado en una ciudad cyberpunk donde el jugador descifra mensajes ocultos manipulando la interfaz y el entorno.
